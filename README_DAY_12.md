# День 12. Первый инструмент MCP — Agent → MCP → Tool → Result

Расширение Дня 11: агент получает запрос пользователя, выбирает MCP-инструмент, вызывает его через MCP и возвращает результат. Упрощённый трекер задач: добавление задач через `add_task`, запрос списка открытых через агента (`get_open_tasks`).

---

## 1. Архитектура Agent → MCP → Tool

```
Пользователь: "Сколько сейчас открытых задач?"
       ↓
Android (Агент): выбирает инструмент get_open_tasks
       ↓
McpClient.callTool("get_open_tasks", {})
       ↓
MCP-сервер: tools/call → выполняет get_open_tasks → возвращает {"open_tasks": N, "tasks": [...]}
       ↓
Агент форматирует ответ: "Открытых задач: N" + нумерованный список задач
       ↓
UI отображает запрос и ответ
```

- **Tools на сервере**: `get_open_tasks` (количество и список открытых задач), `add_task` (добавить задачу с названием). Хранилище задач — in-memory список `TASKS` на сервере.
- **MCP** — сервер обрабатывает `tools/call`; клиент отправляет JSON-RPC и парсит результат.
- **Agent** — на Android: по ключевым словам («задач», «открытых», «tasks») выбирает `get_open_tasks`, вызывает через MCP, парсит JSON и возвращает строку: количество + список названий задач.

---

## 2. Структура (новое / изменённое)

```
mcp_server/
  server.py              # get_open_tasks (count + tasks[]), add_task, handle_tools_call; TASKS in-memory

app/.../mcp/
  McpClient.kt           # callTool(), ToolCallResult, ToolCallResponse
  McpAgent.kt             # выбор инструмента, вызов get_open_tasks, форматирование (count + список задач)
  ToolsViewModel.kt      # agentQuery, askAgent(); toolsListVisible, hideToolsList(); newTaskTitle, addTask()

app/.../ui/
  ToolsScreen.kt          # ServerUrlSection (Подключиться / Скрыть инструменты), AddTaskSection, AgentSection;
                          # список tools показывается только после «Подключиться», скрывается по «Скрыть инструменты»
```

---

## 3. Как агент выбирает инструмент

В `McpAgent.kt` (демо без LLM):

- Промпт приводится к нижнему регистру.
- Если есть подстрока **«задач»**, **«открытых»**, **«tasks»** или **«open»** → вызывается `get_open_tasks`.
- Иначе возвращается подсказка: «Задайте вопрос про открытые задачи…».

---

## 4. Вызов через MCP

1. **Клиент** (после initialize + initialized) отправляет JSON-RPC: `method: "tools/call"`, `params: { "name": "get_open_tasks", "arguments": {} }`.
2. **Сервер** выполняет инструмент и возвращает, например:  
   `{"open_tasks": 2, "tasks": [{"id": 1, "title": "Задача 1", "status": "open"}, ...]}`.
3. **Агент** парсит ответ и формирует текст: «Открытых задач: N» и нумерованный список названий задач.

---

## 5. Список инструментов и добавление задач

- **Список tools** не показывается при старте. Загрузка и отображение — по нажатию **«Подключиться»**. Скрытие — по **«Скрыть инструменты»** (или **«Скрыть»** в заголовке списка).
- **Добавить задачу**: блок «Добавить задачу» — поле «Название задачи» и кнопка **«Добавить»**. Вызывается MCP-инструмент `add_task` с аргументом `title`; задачи хранятся на сервере в памяти. Ответ агента на «Сколько открытых задач?» учитывает добавленные задачи и выводит их список.

---

## 6. Запуск

### Сервер

```bash
cd mcp_server
python3 server.py
```

### Android

1. Укажите URL MCP (эмулятор: `http://10.0.2.2:8765`, устройство: `http://<IP ПК>:8765`).
2. Нажмите **«Подключиться»** (при необходимости — чтобы загрузить список инструментов).
3. **Добавить задачу**: введите название и нажмите **«Добавить»**.
4. **Спросить агента**: введите, например, **Сколько сейчас открытых задач?** и нажмите **«Спросить»**.

---

## 7. Ожидаемый результат

- **Ответ агента** (пример):
  ```
  Открытых задач: 2

  1. Сделать отчёт
  2. Позвонить клиенту
  ```

- Список MCP-инструментов отображается только после «Подключиться» и скрывается по «Скрыть инструменты».
