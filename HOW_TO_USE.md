# Как пользоваться приложением MCP Android

## Что это

Приложение — чат с ИИ-агентом (DeepSeek), который умеет работать с напоминаниями через MCP-сервер: добавлять, показывать и отмечать выполненными.

---

## Перед первым запуском

### 1. API-ключ DeepSeek

- Зарегистрируйтесь на [platform.deepseek.com](https://platform.deepseek.com) и создайте API-ключ.
- В проекте откройте файл **`app/src/main/assets/creds.txt`**.
- Впишите ключ **одной строкой**, без переносов и лишних символов:
  - либо просто: `sk-ваш-ключ-здесь`
  - либо в формате: `DEEPSEEK_API_KEY=sk-ваш-ключ-здесь`
- В файле должна использоваться **только одна строка с ключом**. Строки, начинающиеся с `#`, игнорируются. Если строк несколько, берётся первая подходящая (не пустая и не комментарий).

**Важно:** В заголовок запроса не должны попадать пробелы или перевод строки — иначе будет ошибка (в т.ч. 401 или падение с «Unexpected char 0x0a»). Код читает только первую подходящую строку и обрезает пробелы.

### 2. MCP-прокси (для напоминаний)

Чтобы агент мог добавлять и показывать напоминания:

1. На компьютере (там же, где лежит проект) создайте и активируйте виртуальное окружение и установите зависимости (один раз):
   ```bash
   cd /путь/к/MCPAndroid
   python3.12 -m venv .venv
   source .venv/bin/activate   # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. Запустите прокси:
   ```bash
   source .venv/bin/activate
   uvicorn mcp_proxy:app --host 0.0.0.0 --port 8000
   ```
   Либо одной командой: **`./run_mcp_proxy.sh`** (скрипт сам поднимет venv и зависимости при первом запуске).

3. **Эмулятор Android:** приложение по умолчанию обращается к прокси по адресу **`http://10.0.2.2:8000`** (это «ваш компьютер» с точки зрения эмулятора). Дополнительно ничего настраивать не нужно.

4. **Реальное устройство:** замените `10.0.2.2` на IP вашего компьютера в локальной сети (в коде или через настройки, если вы их добавите). Убедитесь, что устройство и компьютер в одной сети и порт 8000 не закрыт фаерволом.

Подробнее по установке Python и решению проблем — в **README_SETUP.md**.

## Запуск приложения

1. Соберите и установите приложение на эмулятор или устройство (Android Studio: Run).
2. При первом запуске разрешите **уведомления** (для напоминаний), если система запросит.
3. Убедитесь, что MCP-прокси запущен на компьютере (см. выше).

## Как пользоваться

### Чат

- Внизу экрана — поле ввода и кнопка отправки (иконка самолётика).
- Напишите сообщение и нажмите кнопку отправки. Сообщение уйдёт в DeepSeek; ответ появится в чате (слева — ответы агента, справа — ваши сообщения).
- Если агент решает выполнить действие (например, добавить напоминание), он вызывает MCP-инструмент, и в чате появится краткий ответ вроде «Напоминание добавлено» или «Список напоминаний».

### Напоминания

- **Добавить:** напишите в чате, например: «Напомни завтра в 10:00 позвонить маме» или «Добавь напоминание: купить молоко на 15:00».
- **Посмотреть:** спросите: «Какие у меня напоминания?», «Покажи напоминания на ближайшие дни».
- **Выполнить:** когда придёт уведомление о напоминании, нажмите на него — откроется приложение, напоминание будет отмечено выполненным (и при следующем запросе агент увидит обновлённый список).

Список предстоящих напоминаний отображается в верхней части экрана чата (карточки с текстом и датой/временем).

### Уведомления

- Для напоминаний с датой и временем приложение планирует уведомление на указанный момент.
- При нажатии на уведомление открывается чат; напоминание помечается выполненным.

## Если что-то не работает

| Проблема | Что проверить |
|----------|----------------|
| **401 Unauthorized** | В `creds.txt` только одна строка с ключом DeepSeek, без лишних символов и переносов в середине строки. Пересоберите приложение после изменения файла. |
| **Ошибка «Unexpected char 0x0a» в Authorization** | В ключ попал перевод строки. Убедитесь, что в `creds.txt` ключ в одной строке; код читает только первую подходящую строку. |
| **Нет ответа от агента / таймаут** | Есть ли интернет на устройстве; доступен ли DeepSeek API с вашего региона/сети. |
| **Напоминания не добавляются / не показываются** | Запущен ли MCP-прокси на компьютере (`uvicorn mcp_proxy:app --host 0.0.0.0 --port 8000`). На реальном устройстве — правильный ли IP и порт в настройках (для эмулятора — `10.0.2.2:8000`). |
| **Нет уведомлений** | Разрешены ли уведомления для приложения в настройках системы; для Android 13+ нужно разрешение «Публикация уведомлений». |

## Кратко

1. **`creds.txt`** — одна строка с API-ключом DeepSeek, без переносов в середине.
2. **MCP-прокси** — запускать на ПК перед использованием напоминаний; эмулятор подключается к `http://10.0.2.2:8000`.
3. **Чат** — вводите текст и отправляйте; агент отвечает и при необходимости создаёт/показывает напоминания.
4. **Напоминания** — отображаются в чате; уведомления приходят по времени; нажатие на уведомление открывает приложение и отмечает напоминание выполненным.
